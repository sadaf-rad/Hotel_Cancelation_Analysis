# 🏨 Hotel Cancellation Analysis


##  Overview
**Hotel Cancellation Analysis** is a data science project that explores and predicts hotel booking cancellations.  
The goal is to uncover patterns in customer behavior, identify key factors leading to cancellations,  
and build predictive models to help hotels minimize lost revenue.

The project combines **data analysis**, **visualization**, and **machine learning** —  
with interactive insights hosted online via **GitHub Pages**.


## 📊 Key Insights
- **City hotels** experience more cancellations than **resort hotels**.  
- **Long lead times** and **non-refundable deposits** are strong predictors of cancellation.  
- **Bookings made in high-season months** show distinct cancellation spikes.  
- **Customer type** and **market segment** significantly influence cancellation rates.
